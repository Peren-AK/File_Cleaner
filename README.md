# File_Cleaner(ファイル整理ツール)

## はじめに
- 本リポジトリは、私がPythonで開発したローカルフォルダ内のファイルを種類別に自動整理するツールです。
- GUIベースで直感的に操作でき、ドライラン機能（模擬稼働）にも対応しています。
- ご利用いただくことでのトラブル等は一切責任を負いかねます。

## コンセプト
- ダウンロードや作業で増え続けるファイルを、用途ごとに自動で分類できるようにしたい、という考えから開発しました。
- .pdf や .jpg などの一般的なファイル形式に対応し、分類先フォルダ（Images, Documents, Videos, etc.）を自動で作成・振り分けします。
- ドライラン機能を搭載しており、実行前に移動のシミュレーションが可能です。ファイル名の重複にも対応しています。

## ツール概要
- ユーザーはGUI上から整理対象のフォルダを選択し、ボタン一つでファイルの自動整理を行えます。
- ドライランモードでは、実際にファイルを移動せず、どのファイルがどのフォルダに分類されるかをログで確認できます。
- 同名ファイルが既に存在する場合、自動で連番付きのファイル名にリネームして保存されます。

## 利用方法
- 適当なバージョンのpythonをインストールし、ターミナル(コマンドプロンプト)上で'python3 file_cleaner.py'コマンドを実行してください。
- 起動後に表示されるウィンドウで「フォルダを選択」ボタンをクリックし、整理したいフォルダを指定してください。
- 「ドライラン（模擬移動）」にチェックを入れると、実際の移動を行わずに、どのように整理されるかを事前確認できます。
- 「整理を実行」ボタンをクリックすると、指定フォルダ内のファイルが種類（画像・文書・動画など）ごとに自動で分類・移動されます。
- 整理後は、指定フォルダ内にImages, Documents, Videos, Compressed, Music, Othersなどのサブフォルダが生成され、それぞれに分類されたファイルが移動されています。

 | 種類 | 拡張子 |
|------|--------|
| Images | `.jpg`, `.jpeg`, `.png`, `.gif` |
| Documents | `.pdf`, `.docx`, `.doc`, `.txt`, `.xlsx`, `.xls`, `.pptx` |
| Compressed | `.zip`, `.rar`, `.gz` |
| Videos | `.mp4`, `.mov` |
| Music | `.mp3` |
| Others | 上記以外は `Others` フォルダへ分類されます |
